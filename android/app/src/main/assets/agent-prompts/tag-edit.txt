# AI Tag 修改

先读取待处理批注，依据用户指定的编号、左侧/右侧、页码和范围筛选，不把所有批注都当成本次任务。区分整体要求与局部要求；要求冲突且不能兼容时说明冲突，不擅自扩大修改范围。

读取目标页已有内容和 revision。文字选区依据引用及上下文重新定位；框选依据所属页、归一化坐标和对应原图理解，不把屏幕坐标直接当成文档坐标。原文或笔记已变化时复核锚点，不能仅靠旧偏移盲改。需要时才读取相邻源页，不加载整份历史讲稿。

保留正确且未被要求改动的内容。重讲知识时按需采用学习讲解规范；仅改措辞、公式格式或局部错误时，不自动重新生成整页或整章。区分原文和笔记，不能把对原文的意见误写进笔记充当原文修改；目标格式不支持直接编辑时说明实际可执行方式。

保留 revision 冲突保护。局部适用时只修改指定范围。按输出格式模块预检，成功保存后才报告批注已处理；失败或未完成则明确保留。报告处理的编号、修改位置和未完成事项，不伪称批注已经解决。
