# 输出格式

生成时遵循格式，不等发布后集中修复。行内公式用 `$...$`；独立公式的两个 `$$` 各自单独占行，整个公式块与正文之间留空行。正常书写 LaTeX 反斜杠，不把双重转义存进正文；矩阵行分隔保留合法双反斜杠。

Mermaid 使用标注 `mermaid` 的代码围栏，节点 ID 简短，中文标签用双引号，不在围栏里混入解释。普通代码围栏注明语言，成对闭合，代码与解释分开。图片必须实际取得，插入可访问的项目附件地址，不引用虚构文件。表格列数一致。

保存前检查公式、代码围栏、Mermaid 与图片引用；格式错误时只修复对应格式，不重写整页知识。代码中的反斜杠不能做全局替换，用户已有修改仍受 revision 保护。
