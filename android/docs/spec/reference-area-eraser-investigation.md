# 参考应用区域橡皮调查

`EraseAction` 同时遍历 `Pen` 和 `ShapeTool`。相交的自由笔迹调用笔型切分方法，图形调用 `ShapeTool.split`，将擦除前后材料归入同一个动作。

`CircleTool.split` 将圆形轮廓采样为笔迹后调用 `split_v2`；`BezierTool.split` 用 `PathMeasure` 沿曲线取点后调用相同切分路径。参考实现的橡皮可视范围默认为圆角矩形或自定义图片，而当前 PageNote 使用圆形擦除区域，因此本轮显示的圆形边界准确对应现有擦除半径，不宣称形状与参考一致。

PageNote 的识形结果保存在矢量批注层，自由笔迹保存在独立内存模型；混合擦除必须在同一手势中统一快照、更新显示、保存和撤销。早期将矢量拆分后单独异步保存的实验会产生撤销不同步、扩展数据与片段数量问题，已撤出产品代码，实验记录保留在本机参考项目的 `handwriting-kernel/erase-prototype/`。下一步需要先完成统一事务与失败回滚，再按参考源码恢复各图形的切分方式，验证项目文件往返及真实设备交互。
