# Markdown 行内格式命令

## 范围

为 Android 可写笔记编辑器接通桌面同名的粗体、斜体和删除线命令。保留现有 Markdown 源文作为项目权威数据，继续使用 Markwon 编辑器和预览，不引入新解析器或项目格式字段。

本切片最初不包含下划线（桌面使用 HTML）；该命令作为独立切片跟踪于 `features/markdown-underline-formatting.md` 与 task 25。段落格式、插入命令、撤销/重做或剪贴板命令也由各自 SPEC 跟踪。

## 行为

- 命令只在当前页存在可写的 Markdown 源编辑器且应用不忙时启用；预览态、只读项目、无项目或保存/切页锁定时禁用并给出准确原因。
- 粗体、斜体、删除线分别使用桌面源编辑器的 `**text**`、`*text*`、`~~text~~` 语法。
- 有选区时只包裹选中文字，保留其他源文，并在编辑后继续选中原文字。
- 光标折叠时在光标位置插入成对标记和本地化占位文本，并选中占位文本。
- 选区位置使用 Android `EditText` 的 UTF-16 偏移；命令经过原生编辑器变更监听更新页草稿，从而沿用现有自动恢复和 revision-checked 保存流程。格式命令本身不自动保存。
- 其他页、分页符、未选中的当前页内容及项目格式不变。

## 验收（EARS）

- When 用户在可写笔记编辑器中选中 Markdown 文本并选择粗体、斜体或删除线时，Android shall 仅在该选区两侧写入对应桌面语法标记，并保留选区外源文。
- When 用户在编辑器中没有选区时选择行内格式命令，Android shall 在当前光标插入成对标记与本地化占位文本，并选中占位文本供继续输入。
- When 用户处于预览、只读、无项目或编辑锁定状态时，Android shall 禁用这三项命令并显示相应原因，不修改笔记。
- When 用户保存格式修改时，Android shall 复用现有页 revision 冲突保护，只保存当前页；冲突时保留本地草稿且不覆盖外部修改。
- When 编辑后的 Markdown 在预览中渲染时，Android shall 显示粗体、斜体和删除线效果，同时保留可编辑源标记。

## 验证范围

- JVM：精确包裹范围、折叠光标占位、反向/越界选择边界及补充 Unicode 字符的 UTF-16 偏移。
- Android 14/API 34：一项 MainActivity 仪器闭环，从菜单命令格式化选区到保存/重读，并确认其他页不变。
- 构建：受影响 app JVM 测试、该单项 API 34 仪器测试、`:app:assembleDebug`。
- 不运行其他 API、OEM、页面大小、设备或性能矩阵；小米平板 5 Pro 的综合实机验收仍按父 SPEC task 12 执行。
