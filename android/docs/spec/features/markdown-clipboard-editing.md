# Android Markdown 编辑器剪贴板命令

## 范围

为 Android 可写页笔记接通桌面菜单中的剪切、复制和全选。命令操作当前页 Markdown 源文本及 Android 系统剪贴板，不引入项目格式或额外依赖。

本切片不包含粘贴、笔迹复制、撤销/重做、字号、任务列表或链接；这些命令由独立 SPEC 跟踪，不属于本剪贴板切片。

## 行为

- 命令只在当前页可写 Markdown 编辑器存在且应用不忙时启用；预览态、只读、无项目或编辑锁定时不可执行。
- 全选选择当前页完整 Markdown 源文本，不改变内容。
- 复制仅当选区非空时启用，把选中的原文写入系统剪贴板，不修改编辑器或草稿。
- 剪切仅当选区非空时启用，把选中的原文写入系统剪贴板，再从原生 `Editable` 删除选区；编辑器 watcher 负责更新当前页草稿。
- 剪切/复制的范围取执行时编辑器中的 UTF-16 选区并规范化方向；选区外文本保留。
- 剪切只更新草稿，不自动保存；手动保存继续使用现有页 revision 冲突保护，且不改变其他页。

## 验收（EARS）

- When 用户在可写编辑器中选择全选时，Android shall 选中当前页全部 Markdown 源文且不修改源文内容。
- When 用户选择非空文本并执行复制时，Android shall 将精确选中源文写入系统剪贴板且保持当前页草稿不变。
- When 用户选择非空文本并执行剪切时，Android shall 将选区写入系统剪贴板、仅从当前页原生编辑器移除选区，并通过编辑器 watcher 更新草稿。
- When 当前编辑器无选区、处于预览/只读/无项目/忙碌状态时，Android shall 禁用相应命令且不改变剪贴板或笔记。
- When 用户保存剪切后的草稿时，Android shall 仅保存当前页并继续执行既有 revision 冲突保护。

## 验证范围

- Android 14/API 34 平板 AVD：一个聚焦 MainActivity 仪器用例覆盖空选区禁用、复制、剪切、全选和当前页保存；不运行其他 AVD/API/OEM 矩阵。
- 构建：受影响的 `:app:testDebugUnitTest`、单项仪器测试及 `:app:assembleDebug`。
- 小米平板 5 Pro 综合实机验收仍归父 SPEC task 12。
