# Android Markdown 段落格式命令

## 范围

为 Android 可写页笔记接通标题、无序列表、有序列表和引用命令。Android 当前是 Markdown 源码编辑器，因此按桌面 `setupMarkdownTools` 的源码模式回退路径修改文本，而不是模拟桌面富文本编辑器的浏览器 DOM 行为。

标题支持桌面菜单现有的 1、2、3 级。任务列表在源码模式下沿用桌面 `setupMarkdownTools` 的逐行 `- [ ] ` 前缀回退；GFM 预览负责只读呈现，点击复选框不切换状态。字号继续禁用，因为没有 Markdown 源码表示。

## 行为

- 命令仅在当前项目存在可写 Markdown 编辑器且应用不忙时启用。无项目、只读、预览、不可编辑或忙碌时保持禁用。
- 标题命令先显示 1/2/3 级选择；用户选择后才修改源码，分别逐行添加 `# `、`## `、`### `。
- 无序列表、有序列表、任务列表和引用分别逐行添加 `- `、`1. `、`- [ ] `、`> `。
- 按桌面源码回退路径扩展选区：起点扩至 `selectionStart` 所在行行首；终点扩至 `selectionEnd` 所在行行尾或文档末尾。对扩展范围内的每一行加前缀，空行也加前缀；不在扩展范围外插入分隔符。
- 选区反向时规范化，范围越界时夹取到文本边界。偏移采用 Android `EditText`/Kotlin 字符串共同使用的 UTF-16 单位。
- 替换只影响上述范围；完成后光标折叠在变换后范围末尾。编辑器 watcher 更新当前页未保存草稿，不自动保存或改变其他页。
- 应用在执行时再次检查编辑器可写状态；标题弹窗打开期间上下文如变为不可编辑，则不应用修改。

## 验收（EARS）

- When 用户在可写页笔记中选择标题级别时，Android shall 对当前光标行/选区内的各行添加对应 ATX 标题前缀，并将光标放到变换后范围末尾。
- When 用户选择无序列表、有序列表或引用时，Android shall 分别逐行添加桌面源码模式的 `- `、`1. ` 或 `> ` 前缀。
- When 用户选择任务列表时，Android shall 按桌面源码编辑回退路径逐行添加 `- [ ] `，并通过 GFM 预览显示未完成任务项；点按预览复选框不修改项目。
- When 选区跨多行、包含空行、反向或越过文本边界时，Android shall 按本 SPEC 的行扩展规则安全变换，保留范围外文本并保持 UTF-16 选区准确。
- When 用户取消标题级别选择或编辑器不可写/忙碌时，Android shall 不改变 Markdown 草稿。
- When 用户保存当前页笔记时，Android shall 只保存当前页的修改；预览应按现有 Markdown renderer 显示标题、列表和引用。

## 验证范围

- JVM：覆盖三种标题级别、无序/有序/任务列表与引用前缀、多行与空行范围扩展、折叠/反向/越界选区、emoji UTF-16 偏移、范围外文本及末尾光标。
- Android 14/API 34 平板 AVD：聚焦 MainActivity 仪器流程验证可写/只读启用状态、标题级别选择、段落命令、任务列表 GFM span、草稿 watcher、当前页保存与预览；不启动外部 UI。
- 构建：受影响 app JVM 测试、该单项 API 34 AVD 仪器测试、`:app:assembleDebug`。
- 不运行其他 API、OEM、设备、页面大小或性能矩阵；小米平板 5 Pro 真机综合验收仍归父 SPEC task 12。
