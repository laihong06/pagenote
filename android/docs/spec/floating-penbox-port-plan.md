# 悬浮笔盒移植计划

依据参考项目 `PenBoxLayout`、`PenBoxItemTouchHandler`、数据类和 APK 资源表，移植 Android 阅读器悬浮笔盒。截图仅用于运行结果核对。

1. 提取可测试的边界约束、最近边吸附和相对位置恢复计算，覆盖边界及屏幕尺寸改变。
2. 将阅读器笔盒改为画布内浮层，移植方向切换、拖动吸附、锁定与收起，保留现有绘图及工具入口。
3. 按参考结构引入独立笔槽配置和可持久化位置，保留既有笔迹格式与旧项目读取。
4. 核对参考资源和尺寸，验证交互并构建 Android 本地测试包；更新现有 beta PR 和变更日志。记录未实现或未实测的细节。

## 已知范围

应用内位置、顺序与笔槽样式保存在 Android 私有设置中，不更改项目的笔迹文件格式。笔槽支持添加、复制和移除，橡皮作为单独工具；笔盒组支持新建空组、复制、切换、重命名和删除。参考程序的贴纸、自定义工具列表、全部笔型与完整设置面板尚未移植；拖动收缩形态和细节仍待对照，不能宣称像素级一致或真机已验收。

本地参考 APK 的 `PenBoxAdapter` 指定 `ic_pen_normal[_v]_bg`、`ic_pencil[_v]_bg`、`ic_mark_pen[_v]_bg`、`ic_laser_bg_[hv]` 及对应颜色矢量，切换入口引用 `toolbar_h`／`toolbar_v`。`reference_*` 图像和矢量由该 APK 提取或从其二进制矢量恢复，颜色覆盖按笔槽颜色着色；素材的授权信息未确认。资源映射和方法分析见本机参考项目 `penbox-research`。
