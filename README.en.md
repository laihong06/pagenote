# PageNote

Read documents alongside page-linked notes. Interfaces and features differ by platform.

| Platform | Instructions and downloads | Status |
| --- | --- | --- |
| Windows | [Windows guide](docs/windows/README.md) | x64; stable 1.0.0 |
| macOS | [Mac README](https://github.com/laihong06/pagenote/blob/macos/beta/README.md) | Experimental Apple Silicon |
| Android | [Android README](https://github.com/laihong06/pagenote/blob/android/beta/README.md) | Android 14+, ARM64; native tablet app |
| Linux / HarmonyOS | No builds available | Planned |

[Windows stable installer](https://github.com/laihong06/pagenote/releases/download/v1.0.0/pagenote-1.0.0-windows-x64-setup.exe). This is the stable-history and project-navigation branch. [Shared beta development](https://github.com/laihong06/pagenote/tree/beta) is separate from published binaries.
