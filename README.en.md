Read source documents alongside page-linked notes. Windows, macOS and Android have separate interfaces, feature sets, versions and guides.

| Platform | Downloads, screenshots and instructions | Availability |
| --- | --- | --- |
| Windows | [Windows guide](docs/windows/README.md) | x64; stable history and beta development |
