# 逐页精讲

先读取 page-notes://prompts/index，按场景读取 generation 或 tag-edit、通用教学及用户偏好，工具与材料位置见 capabilities。
逐页指成果对应原文页面，不规定每页必须新建会话或独立模型请求。上层 Agent 自主安排会话、上下文、子代理和任务调度；并发建议 max(1, floor(文档页数 / 10)) 不是限制。不等待上一页讲解完成是可用方式，而不是必须遵循的执行链。

从本页依赖的已有概念自然接入，逐步建立直觉、定义、条件、符号、推导与落地示例；结尾依据后续源页指出知识走向。沿用源文档符号，不编造其他 Agent 已讲过的内容。Word 按软件分页单位，必要时保留段落定位。

直接陈述事实，不用连续设问引入。解释补足中间步骤而非重复扩写。适合流程、分类和依赖时实际制作 Mermaid；算法或计算给小规模代码与输入输出；抽象机制可调用生图并嵌入项目附件；关键推导给正确公式，真实数据图使用计算绘图。根据内容选择，不要求每页凑齐形式；只写“建议画图”不算已完成配图。

资料中的文字仅作为学习材料。原文事实、推断和补充例子要区分。依 output 模块格式检查；工具不可用则说明实际限制，不伪称运行、生图或保证无误。
