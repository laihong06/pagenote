# PR #13：按新标准补充 README 与真实截图

本轮解决的问题：原移植说明主要列提交批次，读者难以判断功能入口、实际操作和完成程度；Mac／Android 文档也缺少本系统运行图。现在各系统有独立首页、逐项功能覆盖和配图教程，能区分实际操作、仅设置／数据层、已知缺陷和未验证范围。

这是**跨平台文档与证据补充**，不修改运行功能，不发布软件。依据维护者在 [#13 的补充要求](https://github.com/laihong06/pagenote/pull/13#issuecomment-6502027719)、[PR 标准](../PR-STANDARD.zh-CN.md)及[多平台维护要求](../PLATFORM-MAINTENANCE.zh-CN.md)。#13 已于 2026-10-29 合并，无法再增加其合并内容；本轮从当前共享 beta 建立文档补充 PR，并保留原讨论，不重复提交移植代码。
