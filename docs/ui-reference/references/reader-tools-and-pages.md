# 阅读器工具与页面预览

日期：2026-10-25。范围仅为 HTML 设计样板，不修改 Compose 或 Electron 生产界面。

## 两张参考图

- 书写截图：取左侧工具带的象形笔选择、粗细和颜色切换方式，不照搬整页横线纸或其他菜单。
- 页面预览截图：取右侧可滚动缩略图列表和明显页码，准确定位对应页面。

用户原截图含私人课件内容，仅在聊天中参考，不复制进源码；缩略图均来自样板自己的三页讲义。

## 界面约定

- 左侧工具带缩为 44px，作为安卓 44dp（参考密度约 7 毫米）的样板，展示可区分的钢笔、圆珠笔、荧光笔、激光笔和橡皮擦笔身/笔尖。
- 当前工具以边缘高亮和笔尖前伸表示；再次点击当前笔可收起设置面板。
- 粗细用三种线宽预设和滑块，颜色用色块和自定义颜色选择器；形状用直线、箭头、矩形、椭圆和三角形图标。
- 设置面板预览当前颜色、线宽或形状；点击栏外或 Esc 收起。样板不新增真实手写引擎。
- 阅读器菜单默认收起，可从顶部展开，避免遮挡笔工具；桌面保留原有顶部菜单。
- 右上角页码不再直接输入，改为展示当前页/总页数的预览按钮，左右翻页箭头保留。
- 点击页码，从右侧展开页面预览栏。每项具有原文缩略图、页码与标题，当前页高亮。
- 支持按精确页码或标题筛选；点击条目保存当前示例笔记、跳转并关闭预览。
- 点击预览栏外、关闭按钮或 Esc 收起；键盘焦点回到页码按钮，打开期间焦点保留在预览栏内。
- Markdown 本子使用文字缩略图，不假装有 PDF 页面。

## 定向验证

通过 `node tests/ui-reference.mjs` 批量检查笔型、颜色、线宽、形状预览，以及缩略图加载、
选页、栏外/Esc 关闭和窄屏边界。无需 Android 编译或安装。
