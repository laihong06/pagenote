## 页面

1. **书架**：以参考的侧边导航、内容区、右下角新建/导入入口为平板基准。保留书架绑定与权限恢复、查找、排序、网格/列表、刷新、书籍打开和封面、雨课堂、设置、加载/空/错误状态；窄屏使用可展开的导航。避免用假数据填充空书架。
2. **画布**：参考浅色紧凑的顶部与边缘工具布局，保证原文/笔记、页面操作、缩放和手写/选择可访问；平板优先保证内容空间，窄屏可折叠，不改变 PDF 坐标、触控分发或笔迹保存。
3. **笔盒**：参考常用工具集合、弹出式详细设置和清晰的当前工具状态；连接已有笔、荧光笔、橡皮、形状、颜色和粗细能力。参考中独有的多组预设和工具收藏若现有数据模型不支持，单独实现并验证，或明确作为后续项，不以占位冒充。
4. **设置**：以参考的分组面板为视觉方向，将长列表重组为易找到的类别；保持所有现有设置项、模型设置入口、草稿/取消/保存/错误处理语义及持久化，兼顾系统字号与无障碍。

## 实施细化

- 第一批以现有能力为边界：笔盒沿用当前笔类型、颜色和宽度，不引入尚无数据模型的跨会话多组收藏；工具分组与收藏作为独立后续能力。参考应用的条款尚未同意，未采集其运行界面；手册第 3 页书架、第 6 页画布与工具、第 8 页笔盒、第 25/28 页设置是当前依据。
- 沿用现有窗口尺寸分类：宽窗口侧栏、窄窗口抽屉；提供明显打开、收起与返回路径。先识别已有断点并统一复用，避免在改造中引入互相矛盾的宽度判断。
- 书架分别呈现未绑定、授权失效、空目录、搜索无结果、加载及失败，保留网格/列表和每本书的操作。画布保留双栏比例、切页、输入焦点、笔迹、所有工具浮层层级与触摸交接；尤其保留现有未提交 Markdown S 的裁剪、交互与手动保存。
- 实施前列出 `ReaderSettingsDialog` 全部现有配置和入口，逐项归入新分类；维持保存、取消、失败及外部模型入口，保留已有 testTag 与无障碍语义。不得为外观删除设置。
- 逐屏记录未修改与修改后的 PageNote 实际截图和笔盒展开/设置状态，注明设备、构建与工作树；与参考手册截图分开。模拟器、真机和维护者视觉审核分别记录。
