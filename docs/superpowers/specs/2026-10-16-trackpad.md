# Mac trackpad reading

The reader must respond continuously to two-finger pinch and allow native two-axis inertial scrolling in the document and notes panes. Only the pane under the pointer changes scale; menus, dialogs and app chrome stay fixed. Ctrl/Command + wheel remains available. Small sheets remain centered; once a sheet fills its viewport the content under the pointer stays fixed in both axes.

Scale the complete page, including Markdown typography, PDF text selection, review marks and ink, without reflowing or rebuilding its content during a gesture. Coalesce changes to animation frames, render PDF detail after a 160 ms pause and keep the previous bitmap visible until its replacement is ready. Readable zoom limits: documents 40–400%, notes 65–250%. Fit and Reset notes zoom return to their existing defaults.

Native scrolling must work while annotation tools are active. Zoom must not switch the current page or lose unsaved notes. Cancel pending work when opening another document or rebuilding layout. Preserve existing capture geometry, reading themes, Windows wheel behavior and editing. Build only arm64 and refresh `release/mac-arm64/pagenote.app` for local testing; this is development version 1.0.1-dev.4, not a public release.
