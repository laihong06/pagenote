# Markdown S：开发指导与验收入口

**最新产品要求：[原生渲染与同一 Markdown 文件保存](NATIVE-MARKDOWN.zh-CN.md)。** 主路径已调整为 PageNote 直接绘制组件、保存声明式状态；以下早期 HTML 沙盒方案只保留为历史设计与兼容路径，不代表当前交付方向。

更新：2026-10-30。状态：**设计与实施要求；已有未验收的桌面原型，尚未发布。**

Markdown S 是 PageNote 对 Markdown 的增强约定，不是新的 HTML 官方标准。目标是让学习笔记同时容纳文字、公式、图片、图表、动画和可交互演示，并继续支持保存、编辑、搜索和跨平台阅读。复杂效果应帮助解释知识，正文和操作界面仍保持简洁。

## 首期交付范围

| 模块 | 用户得到什么 | 首期目标 |
| --- | --- | --- |
| 原有笔记 | 普通 Markdown、图片、代码、公式、Mermaid、附件继续使用 | 保留现有行为和保存能力 |
| HTML 演示 | 在笔记内展示布局、CSS 动画、按钮和滑块 | 独立预览，手动运行、停止、重新运行 |
| SVG 演示 | 流程、路径动画、矢量图 | 原生 SVG / SMIL，正文不受样式影响 |
| Canvas 演示 | 粒子、算法过程、动态绘图 | 原生 Canvas 2D，明确资源释放方式 |
| Three.js 演示 | 旋转模型、空间关系、材质和光照 | 固定版本本地依赖；设备不支持时保留源码并解释原因 |
| 数据图表 | 通过数据生成柱状图、折线图 | 校验 JSON，同时提供可读取的数据表 |
| 编辑与兼容 | 修改增强块、保存、撤销、旧端打开 | 保留源码，不静默丢失组件 |

WebGPU、复杂外部模型、专业动画库、独立 HTML 导出和移动端执行为后续独立阶段；能力表里的候选技术不代表已经内置。

## 普通用户怎么使用

文件仍保存为 `.md`。普通正文不需要改变；需要演示时插入专用围栏。例如：

````markdown
## 点一下，理解状态变化

```mds-html
<style>
  button { padding: 12px 24px; border-radius: 12px; }
</style>
<button id="demo">尚未点击</button>
<script>
  document.querySelector('#demo').onclick = function () {
    this.textContent = '状态已经改变';
  };
</script>
```

```mds-chart
{"type":"bar","title":"路线长度","labels":["第一轮","第二轮","第三轮"],"values":[120,95,82]}
```
````

以上是目标语法示例，不能据此推断公开安装包已经支持。验收后的平台教程需要配上实际操作截图；旧版和 GitHub 可以将增强块作为代码展示。

## 当前事实与未完成项

- 集成工作区已有 `src/markdown-s.js`、样式和 Three.js 构建脚本原型，以及部分渲染、保存与导航拦截接线；这些改动**未完成测试，不等于可用交付**。
- 引擎统一接口、可靠的源码编辑和撤销、生命周期治理、离线资源策略、完整安全测试、Android 降级实测和真实截图仍需按实施清单完成。
- 原型源码限制现已按 UTF-8 字节计量，单块上限 200 KiB；每个笔记视图同时最多运行两个演示。
- 本次先完成指导和验收文件；不把原型标记为已经验收，也不更新公开下载。

2026-10-30 开发验证更新：生产构建通过，公式、代码和富文本编辑回归通过；专项验证 HTML 交互、SVG、Canvas 像素绘制、数据图表以及离线 Three.js WebGL 立方体绘制与像素读取。任务作用域和 Mermaid 队列的代次、取消、超时互斥及错误恢复测试通过。这些证据不覆盖全部验收项，Mac／Android 本轮新增内核尚待实测，未公开发布。

## 贡献者必须提交什么

每个实现 PR 列出所覆盖的阶段和验收编号，说明模块入口、操作、结果、停止／撤销方式、限制、影响平台和共享格式兼容性。提交对应平台真实截图、可运行示例、测试命令与结果。未执行项标注“未执行”，不能用设计图或别人的测试代替本次结果。

格式规范版本与软件版本独立：首期约定称 **Markdown S v1**；Windows、macOS、Android 继续使用各自版本号。不因 Windows 新增渲染能力而虚增 Android 已支持的能力。
