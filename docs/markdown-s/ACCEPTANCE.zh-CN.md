# Markdown S 验收标准与记录模板

当前状态：**仅有验收方案；Markdown S 专项未执行、未放行。** 普通 PageNote 的历史测试与本功能测试分开记录。

## 1. 如何使用

每个实现 PR 声明交付阶段、引擎、平台和提交 SHA，从下表选择适用用例。状态只能填“通过／失败／未执行／不适用”；不适用写理由。结果必须有可定位的测试日志、运行环境或截图，不能提前打勾。

本标准用于验收本次新增功能，不追溯推翻已有正式版本。已选择交付的核心功能、数据完整性和权限边界必须验证；尚未选择实现的 WebGPU、未来平台等不构成无限等待条件。发布仍以[发布政策](../RELEASE-POLICY.md)为准。

## 2. 格式与原有内容

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| F01 | 打开原有纯 Markdown、公式、Mermaid、代码、表格和附件笔记 | 显示和编辑不退化；增强组件不是必需字段 |
| F02 | 打开六种约定标记及未知 `mds-unknown` | 已支持标记有正确卡片；未知标记完整显示代码 |
| F03 | 用长围栏、波浪围栏、列表内代码、包含 `$` 与 JS 模板字符串的源码 | 正确识别，不被数学归一化或 HTML 清理改写源码 |
| F04 | 在源码中放中文、emoji、空行、闭合 script 字符串及特殊属性 | 保存重开后源码一致，内容不会溢出到宿主页执行 |
| F05 | 接近／超过 200 KiB UTF-8 上限 | 边界正确；超限解释原因，原文仍可查看与保存 |
| F06 | 文件中包含不闭合围栏或错误 JSON | 明确错误或代码降级，后续正文仍可读，不吞掉文件 |

## 3. 编辑与数据完整性

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| E01 | 源码编辑 → 保存 → 关闭项目 → 重开 | 内容一致；没有把按钮文字、iframe 或错误信息存入笔记 |
| E02 | 富文本／源码切换，修改组件前后正文 | 组件源码不变，原有正文格式保留 |
| E03 | 修改组件 → 撤销 → 重做；取消编辑 | 恢复对应源码和视图；取消不保存临时改动 |
| E04 | 复制整篇、单块、相邻段落；粘贴再保存 | 标记与源码保真，不复制运行时注入的依赖源码 |
| E05 | AI 写入增强块或同步笔记 | 保存为源码，不自动执行，不影响其他页 |
| E06 | 历史恢复、切页、切项目、打开已有项目 | 不串页、不串项目，不丢已确认保存的内容 |
| E07 | 将项目副本交给旧桌面端／Android，再读写返回新版 | 记录确切版本与结果；不能保真时必须明确限制写入，不能默默丢块 |

## 4. 各引擎运行

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| R01 | HTML 示例使用按钮、滑块、CSS 动画、局部样式 | 运行后交互正常；正文和菜单不变 |
| R02 | SVG 路径、SMIL 动画、缩放窗口 | 图形正确且不裁切；源码可查看 |
| R03 | Canvas 动画，连续运行／停止／重跑 | 可控制；停止后不继续绘制，重跑无重复计时器 |
| R04 | 图表的柱／折线、零值、单项、100 项 | 图形可读、标签不执行 HTML，同时有数据表 |
| R05 | 图表负数、非有限值、错类型、长短不一数组及注入标签 | 拒绝或按规范提示；不会执行标签内容；其他笔记正常 |
| R06 | 完全离线运行 Three 几何体并操作视角／参数 | 无 CDN 依赖；产生真实场景，不用静态图片冒充 |
| R07 | 禁用／无法创建 WebGL；模拟上下文丢失 | 解释不支持或运行失败；保留源码，宿主不崩溃 |
| R08 | JS 语法错误、运行异常、Promise 拒绝 | 显示有限错误，仍可停止、改源码、重新运行 |
| R09 | 未支持的滚动动画、View Transition、WebGPU 等 | 能力检测后降级；不能以 API 存在就声称场景验收通过 |

## 5. 权限与隔离

使用合成测试数据和本机测试服务，不接触真实账户或密钥。

| 编号 | 尝试 | 预期结果 |
| --- | --- | --- |
| S01 | 从组件访问父 DOM、父页面的 `pageNotes` 和应用数据 | 被拒绝；不能读取／修改宿主笔记 |
| S02 | 访问 `require`、Node、Electron 桥、磁盘与 AI 配置 | 不可用；没有宿主主动透传 |
| S03 | fetch、XHR、WebSocket、远程 script、CSS、图片、字体 | 按首期 CSP 拦截；无成功的外部资源访问 |
| S04 | 自导航、顶层跳转、meta refresh、改 frame name 后导航 | 桌面宿主仍拦截；不打开外部应用或离开笔记 |
| S05 | 弹窗、下载、表单、嵌套 iframe、摄像头、麦克风、剪贴板 | 不取得未声明权限，不弹系统授权诱导框 |
| S06 | 原始 HTML、SVG、图表标签注入脚本与事件 | 普通通道继续净化；增强代码只在用户启动的沙盒内执行 |
| S07 | 伪造消息、跨组件消息、过期运行实例消息 | 不影响别的块，不触发文件操作或保存 |
| S08 | 错误堆栈、日志、截图与 provenance | 不包含密钥、真实个人笔记、敏感路径或账户信息 |

S07 仅在实现消息通道时适用，否则记录“未提供消息通道”。沙盒不能保证无限循环和 GPU 耗尽都可被同进程可靠终止；测试报告必须说明资源隔离的实际边界，不能承诺任意代码绝对安全。

## 6. 生命周期与性能

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| L01 | 运行后停止；依赖加载途中停止 | iframe 和资源被释放；旧异步任务不能复活组件 |
| L02 | 运行中换页、删除块、切项目和关闭窗口 | 无残留组件、声音、计时器或跨页写入 |
| L03 | 同一视图有 20 个块，逐个尝试运行 | 初始无自动执行；同时最多 2 个运行，超额有清楚提示 |
| L04 | 对相同示例连续运行／停止 20 次 | 无持续增长的 iframe、监听器、Object URL；记录内存前后值和回收时点 |
| L05 | 连续阅读含静态块的长文档，滚动及输入正文 | 记录与普通笔记基线的耗时；不出现由新增调度导致的持续卡死 |
| L06 | 演示离开可见区域／应用进入后台 | 按实现策略暂停或销毁；恢复行为明确 |
| L07 | 启用系统减少动态效果，运行示例 | CSS 及官方 JS 示例尊重该偏好，仍可手动查看内容 |

性能证据记录 CPU、内存、设备、GPU、窗口尺寸、示例规模和观测时长。首期不使用“全设备 60 FPS”“百万粒子不卡”作为宣传或放行结论；需要宣传时必须给出对应设备实测。

## 7. 截图与简洁性审查

截图来自实际软件和被验收的提交。至少覆盖：普通旧笔记、静止卡片、HTML 交互态、SVG／Canvas、Three 场景、数据图表、源码编辑、错误／不支持态、窄窗或移动端降级态。运行截图与教程放在同一平台 `guide/` 下，教程逐步链接图片。

每张注明系统／设备、窗口尺寸、缩放或密度、主题、软件版本、运行提交、是否有未提交改动、示例名称。动态效果另附短录屏或操作步骤，静态图不证明动画正常。

| 审查点 | 判断标准 |
| --- | --- |
| 主次 | 正文为主，演示外框简洁；没有整页闪烁和常驻装饰动画 |
| 控件 | 运行、停止、源码含义明确；不可用状态有原因 |
| 留白与排版 | 卡片、标题、代码不挤压；320–480 CSS px 窄视图及桌面窗口不遮挡按钮 |
| 内容完整 | 图例、轴标签、错误信息和源码入口可见；超长内容可滚动 |
| 主题与缩放 | 浅／深色及 100%／150%／200% 下可读，不出现对比不足和遮挡 |
| 键盘与辅助功能 | 按钮有可读名称、可见焦点、顺序合理；错误状态可感知，无焦点陷阱 |
| 退出与恢复 | 能停止、收起源码、取消编辑、返回正文；不靠重启软件退出普通演示 |

代码检查和截图齐全不等于美学合格。维护者单独记录“可接受／需修改”和具体原因；发起人的视觉反馈作为后续修改依据。

## 9. 放行判断

- **必须修复或撤出相关功能**：数据丢失、项目无法打开、旧笔记核心内容不能读、组件越权、核心流程稳定崩溃、停止／保存明显失效。
- **可记录后按既有政策决定**：非阻断视觉细节、未承诺的设备差异、未来引擎和边缘效果。写入 `KNOWN_ISSUES.md`，说明影响和规避方式。
- **beta 合入**：已声明阶段的必要用例有证据，未完成能力没有被宣称可用。
- **公开包发布**：匹配版本、构建制品与发布检查完成；源码 push 不等于发布。
- **stable 晋级**：按系统实测并取得发起人明确批准；CI 或本文件本身都不构成批准。
