# Android 更新日志

## Unreleased

- 追加或撤销末尾笔迹时保留已有图形与笔迹的文件顺序，改善交错页面删除图形后的撤销；其他混合历史情形仍待完善。

- 图形移动、样式修改和删除会保留同一会话中随后保存的笔迹；编辑目标发生变化或无法唯一确定时停止操作并在底部提示。混合撤销及跨应用并发仍有已知限制。

- 增加未接入阅读器的混合笔迹与批注动作顺序协调实验及单元测试；实际统一撤销和图形擦除尚未完成。

- 混合笔迹与批注历史的冲突检查现在保留页面项目顺序，避免覆盖图层顺序变化；项目重排时可能保守地拒绝恢复。

- 涉及笔迹和批注的历史操作增加已保存页面冲突检查，发现冲突时停止覆盖并提示；混合历史的内存同步和区域擦除仍在开发。

- 图形批注撤销或重做后，在目标可确认时保留选中状态，方便继续编辑；目标不明确时清除选择。本地开发，未公开发布。

- 撤销或重做纯图形批注时保留之后保存的笔迹；检测到其他批注变化时不覆盖，并显示提示。本地开发，未公开发布。

- 区域橡皮移植研究：串联参考圆形采样、默认线段包围盒和切分，新增模拟器测试；尚未接入阅读器或改变 APK 行为。

- 区域橡皮移植研究：加入未接入阅读器的参考笔迹矩形区域切分几何流程与模拟器测试；图形擦除与统一撤销仍在开发。

- 区域橡皮源码移植研究：加入未接入界面的参考圆形轮廓采样与单元测试；图形擦除和完整参考切分仍在开发，用户行为没有变化。

- 阅读器状态提示改为底部居中的圆角信息条；并发错误分别显示，笔迹保存失败保留重试。

- 区域橡皮在触摸和支持的触控笔悬停期间显示实际擦除范围；图形批注的区域擦除仍待实现。本地开发，尚未发布。

- 悬浮笔盒支持新建、复制、切换、重命名和删除笔盒组，并可添加笔槽；各组配置独立保存。本地测试构建，尚未发布。

- 阅读器笔盒悬浮在画布内，支持拖动吸附、位置锁定、笔槽排序、复制和移除；每个笔槽分别记住颜色和粗细。本地测试构建，尚未发布。

- 阅读器橡皮支持按经过的区域切分自由笔迹，一次连续擦除可整体撤销。

- 阅读器书写长笔画时复用已稳定的绘制片段，减少重复生成笔迹路径。

- 阅读器停留识形后立即显示图形并在后台保存，保存期间可继续书写；保存失败时保留原笔迹。

- 阅读器笔盒和笔样式菜单支持滑动及按 0.1 微调笔迹粗细，保留快捷档位。

- 阅读器连续双指缩放不再丢失移动增量，缩放时复用笔迹缓存并减少状态保存开销。

- 阅读器菜单调整为右侧分组面板，按工具、文件和设置切换，并保留原有操作入口。

- 翻页不再等待普通笔迹保存或上一页 PDF 渲染，保存失败仍可重试；取消普通笔迹保存成功的常驻提示，并优化手写停留图形识别的界面响应。

- 更新应用启动图标，适配 Android 不同屏幕密度及自适应图标；本地构建，尚未发布。

- 增加本地真机测试包更新脚本，在固定目录生成按架构区分的 debug APK、校验值和构建来源；不发布公开安装包。

- 阅读器新增画布专注模式，可临时收起笔记区域；笔盒提供笔型与颜色快捷选择。本次为本地开发版本，尚未发布。

- Android 书架新增手机导航和可收起的平板侧栏、新建/导入菜单，并改善目录与书籍布局；笔工具支持长按设置和收起，修复笔身图形越界；设置增加分类快速定位，平板使用右侧设置面板。

- Android 书架重新排列手机顶部搜索与操作入口，宽屏增加快捷侧栏；阅读器笔工具栏跟随主题配色。此为本地进行中的界面改造，尚未发布。

- Android 遗传实验第 8 章本地原型接入 Filament 原生 3D 染色体，支持拖动旋转、点选基因和暂停，状态沿用 Markdown 围栏；Android 14 模拟器已验证代表交互和文件读取，真机与完整重启未验证，尚未发布。
- 修复笔记预览滚动覆盖上方文档区域；模拟器覆盖强制 3D 初始化异常降级、Activity 重建及返回书架重开后的 3D 状态恢复。
- 遗传实验交互时复用现有 3D 场景并更新基因材质，避免每次参数变化都重新创建渲染引擎。
- 3D 视图不再强制屏幕常亮；场景离开可见区域或应用退到后台时暂停自动旋转，恢复可见后继续。
- 修复阅读器手势抢占 3D 横向旋转的问题，场景内纵向拖动可继续滚动笔记；模拟器验证保存后停止进程并重开项目。
- Android 笔记预览新增原生 Markdown S 遗传实验八章界面（染色体、种群、适应度地形、轮盘、交叉、变异、代际图表和可旋转染色体示意），染色体可拖刷位点，轮盘可用左右方向键选择。状态进入现有草稿并沿用原保存入口。项目文件保存后重新读取和多页隔离代表路径已在 Android 14 模拟器通过；完整关闭/重启应用、桌面 Three.js/WebGL 对等和旧笔记全量回归未验收。证据及桌面差异见 [Android Markdown S 指南](guide/markdown-s.md)。
