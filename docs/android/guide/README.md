# Android 配图教程

[平台入口](../README.md) · [功能表](../features.md)

教程和图片保存在同一 guide/ 目录树。每个模块按“入口 → 操作 → 结果”阅读。不得用 Windows 或设计稿替代本系统运行截图；本系统截图未补齐的模块标记待补。

<a id="module-1"></a>

## 1. 项目与书架

从 **启动书架／返回书架** 进入。绑定课件文件夹，在书架查找、打开或导入项目。完成操作后核对当前页、结果与保存反馈；退出面板返回阅读，需要撤回时使用模块提供的撤销／取消。测试开发功能，设备权限／模型按模块要求。

截图状态：待采集对应系统和本模块实际运行画面；不能据此视为布局已验收。
