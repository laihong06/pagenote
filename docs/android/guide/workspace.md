## 双指缩放和平移

在 PDF 原文区域用双指缩放或平移，笔迹与页面一起移动；松手后同步阅读位置。进入双指手势会取消尚未完成的单指笔迹，避免把缩放手势写入画布。

以下为 Android 14／API 34 ARM64 平板模拟器、2560×1600、320 dpi、浅色主题，含 60 条合成笔迹的同一自编页面。改前运行源码 `5f219c619d7d19864aa7fec522d5cc5c62004235`，快速执行目标为 2 倍的手势后仅到约 1.02 倍；改后运行源码 `5fce8429f60888084e51c933eee90303d75f9d4f`，达到 2 倍，继续缩回可回到 1 倍。测试验证手势增量、笔迹对齐和荧光笔透明度；真机延迟与帧率尚未测量。

## 拖动和收起笔盒

1. 在 PDF 阅读页，笔盒默认收起在屏幕边缘；点击笔形按钮展开。笔、颜色、粗细、橡皮和选区仍使用原有工具。
2. 按住笔盒顶部握柄拖动到需要的位置；松手后笔盒靠近屏幕边缘。点击收起按钮可再次缩成小按钮。
3. 笔盒只在本应用阅读页中浮动，不需要“显示在其他应用上层”的系统权限。

## 写字和停笔识别

在 PDF 原文画布用钢笔或圆珠笔书写。画完一笔后保持笔尖在末端约半秒，符合条件的直线、箭头、矩形、椭圆、正向三角形和菱形会先显示规整预览；抬笔后保存为可选中的图形。继续移动会退出预览，可以继续画并再次停住识别；未识别或提前抬笔时保留原始笔迹。荧光笔保持原有笔迹，不自动转换。

保存图形时可以继续写下一笔；保存失败时会回退原始笔迹。新图形采用已有的 `shape` 扩展字段，旧读端可能按基础矩形显示三角形或菱形，跨平台往返尚未验证。

## 页面和 Agent 面板

点击页码可打开侧边选页栏。点击顶部 Agent 打开侧栏并输入任务，提交后侧栏自动收起，任务在应用内继续执行；可以继续阅读、翻页、编辑和使用笔记格式工具。顶部 Agent 入口显示运行、完成或需处理的状态，点击可重新打开任务及结果。手机用小标记表示状态，点击图标查看详情。点击“关闭”、侧栏外部或系统返回也可收起面板。

Agent 写笔记时与自动保存协调：同页有未保存草稿时不会直接覆盖；如果写入期间出现新的手动输入，草稿和原版本会保留并提示处理冲突。更换项目、退出应用或系统回收进程后，不保证任务继续或恢复。需要用户自行配置模型并联网，实际模型服务尚未在本轮测试。

## 窄屏和编辑

在窄屏或竖屏，点击“原文／笔记”切换主视图；已输入的草稿会保留。PDF 笔工具用于原文画布，切到笔记时不遮挡文本输入。

## 自动保存与离开

编辑笔记后应用会自动写入项目文件；正常保存不会弹出“已保存”。翻页或回书架时，应用会等当前页最新编辑写入完成。保存失败、目录权限失效或文件被其他程序修改时，应用保留当前页和草稿并显示错误／重试入口；请先解决保存问题再离开。重载在有未保存修改时不可点击。

如果外部修改造成冲突，可以选择“复制草稿并重载”，确认后先把草稿放到剪贴板，再载入项目中的版本。需要时可粘贴草稿并重新编辑；重载过程中出现的新编辑会被保留。

历史快照按页面限频，防止连续输入产生过多历史文件。草稿恢复记录和项目文件保存是两回事：恢复记录不能代替成功写入项目文件。

连续手写时，后台会合并尚未写入的旧笔迹快照，保存当前页的最新内容。点击翻页或回书架后仍要等最新笔迹与笔记写入成功；如果项目所在存储很慢，可能仍有短暂等待。写入失败会保留当前页并提示处理。

## 范围

本次重做书架与阅读工作区的主要布局、浮动笔盒、选页／Agent 入口和自动保存体验。OCR、录音、闪卡、Office 等既有功能仍使用其原有业务流程，不代表本轮完成了这些外部服务或真机手写笔验收。屏幕截图由作者采集，维护者的布局审查另行记录。
