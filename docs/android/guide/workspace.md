## 打开和阅读

在书架选择项目。平板横屏同时显示原文与逐页笔记，拖动中间分隔线可调整比例。顶部页码打开选页栏，点击目标页后返回阅读；主页按钮返回书架。

## 拖动和收起笔盒

1. 在 PDF 阅读页，笔盒默认收起在屏幕边缘；点击笔形按钮展开。笔、颜色、粗细、橡皮和选区仍使用原有工具。
2. 按住笔盒顶部握柄拖动到需要的位置；松手后笔盒靠近屏幕边缘。点击收起按钮可再次缩成小按钮。
3. 笔盒只在本应用阅读页中浮动，不需要“显示在其他应用上层”的系统权限。

## 页面和 Agent 面板

点击页码可打开侧边选页栏。点击顶部 Agent 打开侧栏；点击“关闭”、侧栏外部或系统返回即可收起。Agent 执行期间也可收起面板，回到当前笔记。配置模型和实际发送请求仍由用户决定；截图未发送模型请求。

## 窄屏和编辑

在窄屏或竖屏，点击“原文／笔记”切换主视图；已输入的草稿会保留。PDF 笔工具用于原文画布，切到笔记时不遮挡文本输入。

![竖屏笔记](images/workspace/after-narrow.png)

## 自动保存与离开

编辑笔记后应用会自动写入项目文件；正常保存不会弹出“已保存”。翻页或回书架时，应用会等当前页最新编辑写入完成。保存失败、目录权限失效或文件被其他程序修改时，应用保留当前页和草稿并显示错误／重试入口；请先解决保存问题再离开。重载在有未保存修改时不可点击。

如果外部修改造成冲突，可以选择“复制草稿并重载”，确认后先把草稿放到剪贴板，再载入项目中的版本。需要时可粘贴草稿并重新编辑；重载过程中出现的新编辑会被保留。

历史快照按页面限频，防止连续输入产生过多历史文件。草稿恢复记录和项目文件保存是两回事：恢复记录不能代替成功写入项目文件。

连续手写时，后台会合并尚未写入的旧笔迹快照，保存当前页的最新内容。点击翻页或回书架后仍要等最新笔迹与笔记写入成功；如果项目所在存储很慢，可能仍有短暂等待。写入失败会保留当前页并提示处理。

## 范围

本次重做书架与阅读工作区的主要布局、浮动笔盒、选页／Agent 入口和自动保存体验。OCR、录音、闪卡、Office 等既有功能仍使用其原有业务流程，不代表本轮完成了这些外部服务或真机手写笔验收。屏幕截图由作者采集，维护者的布局审查另行记录。
