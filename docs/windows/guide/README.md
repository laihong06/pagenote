# Windows 正式版操作与历史截图

[返回 Windows README](../README.md)。下列图片来自已有稳定文档，本轮沿用，不伪称新截图，也不用于 Mac／Android 验收。

## 阅读与笔记

打开课件，左侧阅读原文，右侧查看对应页笔记。切页时核对笔记对应关系。

![Windows 双栏阅读](../../images/paired-reading.png)

## 公式、代码和流程图

在笔记中使用对应 Markdown 语法；复杂公式与图表请对照渲染结果。

![Windows Markdown 表达](../../images/markdown-rendering.png)

## 编辑与保存

展开编辑区后修改笔记，使用保存并重新打开确认。不要把其他平台的工具栏当成本系统入口。

![Windows 笔记编辑](../../images/note-editing.png)

## 留下修改意见

选择文字或框选区域，填写本次意见；AI 处理范围以所选内容和请求为准。

![Windows 选区批注](../../images/ai-annotation.png)
