下面复用仓库已有 Windows 实际运行图。本轮没有 Windows 主机，图片原始基线和未验证项目全部保留；不把历史图或一个平台的通过写成当前全平台验收。菜单名称以实际语言为准。

<a id="module-1"></a>

## 1. 从书架打开项目

1. 启动后选择书架目录，在系统文件选择器确认。取消会保留原书架。
2. 点击项目封面打开，阅读器左上角返回按钮回到书架。
3. 项目仍在原目录，移除书架入口不等于删除原文件；迁移前复制完整项目。

![Windows 书架](images/current/bookshelf.png)

<a id="module-2"></a>

## 2. 双栏阅读与切页

左侧显示原文，右侧显示当前页笔记。用页码切换对应页，两侧各自滚动；底部缩放调整材料视图。翻页前检查笔记保存反馈，失败提示需要处理后再关闭。此图使用合成材料，不是在线生成。

![Windows 双栏阅读](images/current/reading.png)

<a id="module-3"></a>

## 3. 编辑笔记并回到阅读

从编辑菜单的文件编辑入口选择笔记区域，进入展开编辑状态。修改正文后使用完成编辑／返回双栏，检查本地保存提示。键盘撤销用于相应编辑器的历史，不能因此推断任意外部文件操作均可撤销。本轮沿用布局图，没有重做冲突恢复或安装升级测试。

![Windows 编辑布局](images/current/editing.png)

<a id="module-4"></a>

## 4. 公式、代码和流程图

在笔记源码中写 LaTeX 公式、语言代码围栏或 Mermaid 流程图，返回预览查看结果。阅读图展示三种实际渲染；数据或语法错误要回到源码修正。增强课件另见[原生模板教程](markdown-s.md)，不能把普通渲染当作 OCR 识别结果。

<a id="module-5"></a><a id="module-6"></a>

## 5–6. 选区意见与 AI 工作台

选择文字或框选范围后，可记录局部修改要求；整体要求从 AI 标注／修改意见菜单进入对应侧的工作台。关闭工作台回到阅读。外部 AI 客户端通过 MCP 读取材料和要求，需用户自行配置和授权。

下面只证明工作台真实存在，精确选区、Tag 创建、请求和应用结果没有本轮连续证据，不能称为已验证。

![Windows AI 工作台](images/current/ai-workbench.png)

<a id="module-7"></a>

## 7. 提示词与模型设置

设置中选择对应 AI 模块后编辑并保存；恢复默认只针对当前模块。密钥不应出现在截图或项目样例。当前 Windows 新设置截图待补，Mac 原生设置不作为此项证据。本轮未发送真实模型请求。

<a id="module-8"></a>

## 8. 展开画笔工具

点击左侧画笔入口，按需要选择笔、颜色和粗细；回到选择工具继续选择文字。面板按需展开以保留内容空间。此图仅证明工具布局，实体笔、压感、整套擦除和历史操作仍需专门验证。

![Windows 笔工具展开](images/current/ink-tools.png)

## 9–14. 尚缺当前过程图的模块

| 模块 | 使用条件与退出／结果 | 本轮证据边界 |
| --- | --- | --- |
| OCR | 安装兼容本地模型，识别后人工核对；取消识别返回阅读 | 未执行真实识别；普通渲染图已从 OCR 证据移除 |
| Office | 本机 Office 和授权可用时导入／外部编辑，外部保存后回到软件刷新 | 未操作真实 Office，不把 Android 引擎切片当 Windows 行为 |
| 雨课堂 | 登录账号选课程，导入历史课件或授权采集；结束后停止采集 | 无本轮账号请求，真实课堂还涉及单独授权 |
| 历史／备份 | 从菜单恢复；迁移时先复制完整目录，保留原件供核对 | 没有本轮恢复过程图；本机偏好和外部账号不等于项目文件 |
| 附件／导出 | 插入资源，或选导出格式和保存位置，检查输出文件 | 取消选择器不等于导出成功；输出文件尚未复验 |
| 主题／缩放／位置 | 从设置和阅读器调整显示；退出面板继续阅读 | 已有浅色阅读图；深色、窄窗与重开位置过程待补 |

这些缺口不自动变成新发布的全环境门槛；维护者可按具体影响审查，结论另记。
