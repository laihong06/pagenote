# PageNote Windows 正式版

PageNote 将原文与对应页讲解并排显示。Windows 版使用鼠标、键盘和桌面文件操作；Android 与 Mac 有自己的界面和能力，请从[项目总览](../../README.md)选择系统。

## 正式下载

当前公开正式版：**1.0.0**，Windows x64。

[安装包](https://github.com/laihong06/pagenote/releases/download/v1.0.0/pagenote-1.0.0-windows-x64-setup.exe) · [完整便携 ZIP](https://github.com/laihong06/pagenote/releases/download/v1.0.0/pagenote-1.0.0-windows-x64.zip) · [源码](https://github.com/laihong06/pagenote/releases/download/v1.0.0/pagenote-1.0.0-source.zip) · [说明与校验值](https://github.com/laihong06/pagenote/releases/tag/v1.0.0)。

退出旧程序再安装；ZIP 完整解压，不单独搬动 exe。需要 Office 转换时准备本机相应软件；OCR 和 AI 外部依赖见已知问题。本次仅重整说明，不重新打包或替换已发布制品。

## 本系统功能与操作

| 模块 | 作用与入口 |
| --- | --- |
| 双栏阅读 | 打开支持的课件，在左侧读原文、右侧查看对应页笔记 |
| 笔记编辑 | 进入编辑区，用 Markdown、公式、代码与图表表达；保存并核对结果 |
| 批注与修改意见 | 选择文字或区域，留下具体意见，通过 AI 协作修改指定内容 |
| AI 协作 | 使用实际连接的客户端／服务，不等于应用内置大模型 |
| Windows 文档适配 | 按本机 Office 及系统应用能力处理原文，不能套用 Android 操作 |

[操作教程与截图](guide/README.md) · [版本更新](../../CHANGELOG.md) · [已知问题](../../KNOWN_ISSUES.md)。

要体验未发布的新功能，请查看 [Windows beta 独立说明](https://github.com/laihong06/pagenote/blob/windows/beta/README.md)；本正式版不包含后续原生 Markdown S 等开发改动。
