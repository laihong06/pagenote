# 桌面书架技术设计

状态：已实现，依据 [已确认需求](requirements.md)；实测范围见 [验证记录](validation.md)。

## 方案

在现有 Electron / 本机 Express / Vite 架构中增加书架模块，Windows 与 Mac
复用同一前端。不替换项目打开、编辑、保存或雨课堂协议模块。

目录扫描只读取轻量项目元数据，不调用 `projects.open()`，不复制 PDF、导入
笔记或转换 Office。用户选书后才使用既有打开流程。

## 模块与接口

- `desktop/bookshelf.cjs`：本机目录设置、受限发现、项目身份、可移植封面元数据、
  安全封面文件访问。放在现有 `desktop/**` 打包范围，不新增顶层运行时文件。
- `src/bookshelf.js` / `src/bookshelf.css`：书架视图、搜索/排序、封面设置和生命周期；
  `src/book-covers.js`：按需缩略图及资源释放。主入口只保留导航和现有读写流程连接。
  书架工具栏保留独立的“最近文档”选择器，避免桌面原本隐藏的工具栏让外部旧文档失去入口。
- `server.mjs`：注册书架配置、列表、封面与图片上传路由，复用同源保护和上传链路。
- `projects.mjs`：提取可复用的项目创建函数，默认父目录由书架配置提供；保留既有
  `/api/projects` 以及“导入左侧”语义。
- `desktop/preload.cjs` / `desktop/main.cjs`：增加仅供本窗口使用的目录选择桥接及
  原生“书架”菜单，不向渲染进程开放任意文件系统执行能力。
- `desktop/mac-settings.cjs` / `.swift`：在现有原生设置“通用”页显示书架目录和
  修改按钮；Windows 与 Mac 后备网页设置提供同等入口。

## 本地状态与身份

- `data/bookshelf.json` v1 保存本机目录、`grid|list`、`updated|name`；原子写入，
  不与 AI 凭据、项目清单或可移植封面文件混用。
- 每本书的 `key` 为规范化项目文件绝对路径的 SHA-256，不以名称或 manifest ID
  单独作为书架身份。同 ID 的两个不同目录必须分别显示，切换前完成当前保存。
- 阅读位置使用独立本机键 `bookshelf-position:<key>`，附带 manifest ID 校验，
  沿用现有页码恢复流程；替换了身份的项目不得继承旧位置。
- 绑定目录变更后淘汰旧扫描索引；异步旧扫描或缩略图不得覆盖新目录的结果。
  配置只有在新目录验证成功后才替换，取消或失败保持旧绑定。

## 发现与安全

扫描深度 8、最多 2,000 目录及每目录 10,000 条目；使用可提前停止的目录遍历，
不先把无限目录读入内存。识别 `project.pagenote` 与既有旧文件名后停止深入该项目。
项目清单最多 1 MiB、可选封面 JSON 最多 64 KiB；可读性、格式、ID 和相对链接
校验失败应附警告。根目录读取失败与真正空目录分开报告。

遍历不跟随目录符号链接。源文档、封面与 assets 在读取/写入时校验实际路径仍位于
对应项目内；路由通过当前扫描索引的 key 取资源，不接受任意绝对资源路径。重新
读取时再次校验，项目被移动或删除时返回可恢复错误。

## 封面契约与展示

复用 Android `src/bookshelf.json` v1 的原有字段和约束：标题最长 200 字符，
`cover=default|paper|pdf|image`，`page` 从 0 开始，`asset` 仅安全文件名，
`paper=sage|rose|sky|graphite`。未知版本或损坏文件警告并回退，不覆写源文稿。

图片存入 `src/assets/`；上传只接受经已有 Sharp 解码验证的栅格图片，输入上限
20 MiB / 20,000,000 像素，缩小至 1200x1600 内并保存为 PNG。取消或失败不改变
封面设置；重置不删除可能仍被其他内容引用的图片。

PDF 使用已有 PDF.js，完整适应封面；Office 只读取已有 `manifest.preview`。
缩略图采用视口按需加载、最多 2 个并行任务、最多 128 项且合计 48 MiB 的内存
LRU，移出书架或更换目录取消任务并释放 canvas / PDF 文档 / Blob URL。缓存键包含
项目 key、文件时间/大小和封面设置。封面失败不改用 `Note` 冒充成功 PDF 预览。

书架复用 Android 的中性背景、横向层板、144:192 封面比例和四种纸本配色；默认
纸本固定写 `Note`，实际标题另列。桌面使用现有主题/语言机制及 Lucide 工具图标，
不引入新的 UI 框架，不添加云同步横幅。

## 导航与创建

新增 `window.pageNotes.showBookshelf()`；它先等待 `finishEditing()` 成功，再隐藏
阅读器并刷新书架。保存失败不切页。`openDocument()` 成功后统一切回阅读器，保证
双击、最近文档、文档控制及项目打开都不被书架遮挡。capture 隐藏窗口不启动书架。

普通冷启动移除“自动打开 last-document”，显式文件打开仍经现有 launcher 排队。
书架可见时暂停仅服务隐藏阅读器的渲染及预取，雨课堂的连接和写入队列继续运行；
首张课件建立项目后刷新书架但不擅自打断用户当前阅读。

普通新建与书架导入默认父目录取绑定根目录；导入 PDF/Markdown 创建独立标准项目，
不得复用当前 doc.id 绑定左侧。阅读器“导入左侧”保持原行为。雨课堂面板增加可见
目标目录及更改入口，绑定有效时不再次强制弹出文件选择器。

## 验证边界

使用临时目录做 Node 存储/路由测试，以及隔离 Electron 配置的定向书架 UI 流程；
覆盖保存失败、重启、相同 ID 的两本书、失效目录、符号链接和 Android sidecar。
仅更新 Mac arm64 本地包，在固定入口正常退出/重开后验收。Windows 无实际运行
环境则明确记录，不扩张全量 Office、设备或真实雨课堂测试。
