pagenote

pagenote 将源文档与逐页 Markdown 笔记放在同一项目中。

从文件菜单新建或打开项目；导入文档与笔记后，两侧按页面关联。

使用选择工具选中文字或区域，再添加 AI 标注；双击编号打开标注画布，右键可删除。

手形工具用于平移页面。画笔支持手写、荧光标记和擦除。

从编辑菜单选择文档或笔记区域。Word 编辑需要本机 Microsoft Word。

触控板双指捏合缩放所在页面，双指上下、左右移动。也可按 Ctrl 或 Command 加鼠标滚轮缩放；点击“适应”或“重置笔记缩放”恢复。Markdown 支持代码高亮、公式、图片、表格和 Mermaid。

通过 AI 标注菜单复制 MCP 配置，在外部 AI 客户端连接。软件本身不内置 AI 服务或上传项目。

移动项目时请保留整个文件夹及 src 子目录。新版项目入口为 project.pagenote，旧版 JSON 项目仍可打开。

设置

书架目录

左侧翻页时，右侧讲解轻柔淡入。关闭后立即切换。

左侧 Word 编辑或右侧编辑时，默认展开。可拖动分界线拉回双栏，也可点击“返回双栏”。关闭后保持当前双栏宽度。设置会自动保存。

AI 设置

修改内置教学规则与用户偏好，连接的 AI 可直接按入口读取，无需复制提示词。

系统提示词保存后重新连接客户端；模块修改在 AI 下次读取时生效。仅保存当前选中的模块。

逐页精讲技能按任务启用，不会把摘要、翻译或简答强制变成讲课。此设置不改变工具权限。

历史版本

每次保存都会自动保留笔记版本。恢复前会保留当前内容；原始文档和附件不受影响。

选择一个版本查看内容。
